# CSAPP Data Lab 学习笔记

## 实验概述
Data Lab是CSAPP第一个实验，要求使用有限的位运算操作符实现各种函数，帮助理解数据的位级表示和操作。

## 详细解题思路

### 1. bitXor - 用&和~实现异或
**题目要求**：只用`~`和`&`实现`x^y`

**思维过程**：
- 异或的定义：相同为0，不同为1
- 分析：`x^y`等价于`(x且非y) 或 (非x且y)`
- 转换为德摩根定律：`A或B = ~(~A且~B)`
- 所以`x^y = ~(~(x&~y) & ~(~x&y))`

```c
int bitXor(int x, int y) { 
    return ~(~(~x & y) & ~(x & ~y)); 
}
```

### 2. tmin - 返回最小补码数

**题目要求**：返回最小的32位补码数

**思维过程**：

- 32位补码的最小值是-2³¹ = 0x80000000
- 二进制表示：1后面跟31个0
- 直接用移位：1左移31位

```c
int tmin(void) { 
    return 1 << 31; 
}
```

### 3. isTmax - 判断是否为最大补码数

**题目要求**：判断x是否为最大补码数

**思维过程**：

- 最大补码数：0x7FFFFFFF
- 按位取反后：0x80000000（最小补码数）
- 利用性质：只有Tmax取反后等于Tmin
- 检查`~x`是否等于`1<<31`

```c
int isTmax(int x) { 
    return !(~x ^ (1 << 31)); 
}
```

### 4. allOddBits - 检查所有奇数位是否为1

**题目要求**：检查1,3,5...31位是否都为1

**思维过程**：

- 需要构造掩码0xAAAAAAAA（奇数位全为1）
- 由于常数限制，只能用0xAA构造
- 先构造0xAAAA，再扩展到32位
- 用按位与提取奇数位，然后比较

```c
int allOddBits(int x) {
    int mask = 0xAA + (0xAA << 8);  // 构造0xAAAA
    mask = mask + (mask << 16);     // 扩展到0xAAAAAAAA
    return !((x & mask) ^ mask);    // 检查奇数位是否都为1
}
```

### 5. negate - 实现取负

**题目要求**：返回-x

**思维过程**：

- 补码取负的规则：按位取反加1
- 这是补码表示的基本性质

```c
int negate(int x) { 
    return ~x + 1; 
}
```

### 6. isAsciiDigit - 判断ASCII数字

**题目要求**：判断x是否在0x30-0x39范围内

**思维过程**：

- 需要同时检查下界和上界
- 下界检查：`x - 0x30 >= 0`，即`x + (~0x30 + 1) >= 0`
- 上界检查：`0x39 - x >= 0`，即`0x39 + (~x + 1) >= 0`
- 利用符号位判断：非负数的符号位为0

```c
int isAsciiDigit(int x) {
    int lower_bound = x + (~0x30 + 1);    // x - 0x30
    int upper_bound = 0x39 + (~x + 1);    // 0x39 - x
    return !((lower_bound >> 31) | (upper_bound >> 31));
}
```

### 7. conditional - 实现条件选择

**题目要求**：实现`x ? y : z`

**思维过程**：

- 关键是构造掩码：x非零时选y，x为零时选z
- `!x`：x非零时为0，x为零时为1
- `~(!x) + 1`：x非零时为全1，x为零时为全0
- 用掩码选择：全1时选择y，全0时选择z

```c
int conditional(int x, int y, int z) {
    int is_zero = !x;
    int mask = ~is_zero + 1;  // x非零时全1，x为零时全0
    return (mask & z) | ((~mask) & y);
}
```

### 8. isLessOrEqual - 实现小于等于

**题目要求**：实现`x <= y`

**思维过程**：

- 基本思路：检查`y - x >= 0`
- 但要处理溢出情况
- 分情况讨论：
  1. x和y同号：直接比较`y - x`的符号
  2. x和y异号：x负y正时返回1，x正y负时返回0

```c
int isLessOrEqual(int x, int y) {
    int sign_x = (x >> 31) & 1;
    int sign_y = (y >> 31) & 1;
    int sign_diff = sign_x ^ sign_y;        // 符号是否不同
    int diff = y + (~x + 1);                // y - x
    int sign_diff_res = (diff >> 31) & 1;   // 差值的符号
    return (sign_diff & sign_x) | (!sign_diff & !sign_diff_res);
}
```

### 9. logicalNeg - 实现逻辑非

**题目要求**：不用`!`实现逻辑非

**思维过程**：

- 关键观察：只有0的相反数还是0（或者说0的符号位和-0的符号位都是0）
- 非零数x：x和-x中至少有一个符号位为1
- 零：0和-0的符号位都是0
- `x | (-x)`：零时为0，非零时最高位为1

```c
int logicalNeg(int x) { 
    return ((x | (~x + 1)) >> 31) + 1; 
}
```

### 10. howManyBits - 计算表示所需位数

**题目要求**：返回表示x所需的最少位数

**思维过程**：

- 负数先转换为对应正数：如果是负数，使用~x
- 用二分查找思想：先检查高16位，再检查高8位...
- 关键是构造条件判断：用`(x | (~x + 1)) >> 31`判断非零

```c
int howManyBits(int x) {
    int sign, bits, tmp;

    // 获取符号位
    sign = x >> 31;

    // 如果是负数，转换为 ~x
    // 如果是正数，保持不变
    x = (sign & (~x)) | ((~sign) & x);

    bits = 0;

    // 检查高16位是否有1
    tmp = x >> 16;
    tmp = (tmp | (~tmp + 1)) >> 31; // 如果tmp非零则为-1，否则为0
    tmp = tmp & 1;                  // 转换为0或1
    bits += tmp << 4;
    x >>= tmp << 4;

    // 检查高8位是否有1
    tmp = x >> 8;
    tmp = (tmp | (~tmp + 1)) >> 31;
    tmp = tmp & 1;
    bits += tmp << 3;
    x >>= tmp << 3;

    // 检查高4位是否有1
    tmp = x >> 4;
    tmp = (tmp | (~tmp + 1)) >> 31;
    tmp = tmp & 1;
    bits += tmp << 2;
    x >>= tmp << 2;

    // 检查高2位是否有1
    tmp = x >> 2;
    tmp = (tmp | (~tmp + 1)) >> 31;
    tmp = tmp & 1;
    bits += tmp << 1;
    x >>= tmp << 1;

    // 检查高1位是否有1
    tmp = x >> 1;
    tmp = (tmp | (~tmp + 1)) >> 31;
    tmp = tmp & 1;
    bits += tmp;
    x >>= tmp;

    // 检查最后一位
    bits += x;

    // 加上符号位
    return bits + 1;
}
```

## 浮点数部分详细解析

### IEEE 754格式回顾

- **符号位(1位)** | **指数位(8位)** | **尾数位(23位)**
- **规格化数**：值 = (-1)^符号 × 1.尾数 × 2^(指数-127)
- **非规格化数**：值 = (-1)^符号 × 0.尾数 × 2^(-126)

### 11. floatScale2 - 浮点数乘以2

**题目要求**：返回2*f的位级表示

**思维过程**：

1. **提取各部分**：用位掩码分离符号、指数、尾数
2. **分类讨论**：
   - NaN/无穷大：指数全1，直接返回
   - 零：特殊处理
   - 非规格化数：尾数左移（相当于×2）
   - 规格化数：指数+1（相当于×2）
3. **溢出检查**：指数溢出时返回无穷大

```c
unsigned floatScale2(unsigned uf) {
    unsigned sign = uf & 0x80000000;  // 提取符号位
    unsigned exp = (uf >> 23) & 0xFF; // 提取指数位（8位）
    unsigned frac = uf & 0x7FFFFF;    // 提取尾数位（23位）

    // 情况1：NaN 或无穷大（指数全1）
    if (exp == 0xFF) {
        return uf;  // 保持不变
    }

    // 情况2：零（指数和尾数都为0）
    if (exp == 0 && frac == 0) {
        return uf;  // 0×2还是0
    }

    // 情况3：非规格化数（指数为0但尾数非0）
    if (exp == 0) {
        // 非规格化数乘2 = 尾数左移1位
        // 值从 0.尾数×2^(-126) 变为 0.(尾数<<1)×2^(-126)
        frac = frac << 1;
        return sign | (exp << 23) | frac;
    }

    // 情况4：规格化数（指数1-254）
    // 规格化数乘2 = 指数加1
    // 值从 1.尾数×2^(exp-127) 变为 1.尾数×2^(exp+1-127)
    exp = exp + 1;

    // 检查溢出：指数变为255或更大
    if (exp >= 0xFF) {
        return sign | 0x7F800000; // 返回同符号的无穷大
    }

    return sign | (exp << 23) | frac;
}
```

### 12. floatFloat2Int - 浮点数转整数

**题目要求**：将浮点数转换为整数

**思维过程**：

1. **提取各部分**并分类处理
2. **计算实际指数**：exp - 127
3. **构造完整尾数**：添加隐含的1
4. **位移调整**：根据指数确定小数点位置
5. **应用符号**

```c
int floatFloat2Int(unsigned uf) {
    unsigned sign = uf & 0x80000000;  // 符号位
    unsigned exp = (uf >> 23) & 0xFF; // 指数位
    unsigned frac = uf & 0x7FFFFF;    // 尾数位

    // 情况1：NaN 或无穷大
    if (exp == 0xFF) {
        return 0x80000000u;  // 溢出标志
    }

    // 情况2：零或非规格化数（太小，整数部分为0）
    if (exp == 0) {
        return 0;
    }

    // 计算实际指数（去除偏置）
    int actual_exp = exp - 127;

    // 情况3：太大，超出32位整数范围
    // 最大正整数2^31-1需要31位，所以actual_exp>=31就溢出
    if (actual_exp >= 31) {
        return 0x80000000u;
    }

    // 情况4：小数（actual_exp < 0）
    if (actual_exp < 0) {
        return 0;
    }

    // 情况5：可转换的规格化数
    // 添加隐含的前导1：1.尾数 = (1<<23) | 尾数
    frac = frac | 0x800000;  // 尾数变成24位：1xxxxxxx...

    // 根据指数调整小数点位置
    // actual_exp表示小数点右移的位数
    if (actual_exp <= 23) {
        // 需要右移：去掉小数部分
        frac = frac >> (23 - actual_exp);
    } else {
        // 需要左移：整数部分变大
        frac = frac << (actual_exp - 23);
    }

    // 应用符号
    if (sign) {
        return -frac;  // 负数
    } else {
        return frac;   // 正数
    }
}
```

### 13. floatPower2 - 计算2的x次方

**题目要求**：返回2.0^x的位级表示

**思维过程**：

1. **理解目标**：构造浮点数表示2^x
2. **规格化数情况**：2^x = 1.0 × 2^x，所以指数部分就是x+127
3. **边界处理**：
   - 太大：返回正无穷
   - 太小：返回0或非规格化数
4. **非规格化数**：当指数为0时，值为0.尾数×2^(-126)

```c
unsigned floatPower2(int x) {
    // 计算加上偏置后的指数
    int exp = x + 127;

    // 情况1：太大 - 指数>=255，返回正无穷
    if (exp >= 255) {
        return 0x7F800000;  // +INF：符号0，指数全1，尾数全0
    }

    // 情况2：可能的非规格化数或太小的情况
    if (exp <= 0) {
        // 完全太小的情况：连非规格化数都表示不了
        // 非规格化数最小值是1×2^(-149) = 2^(-149)
        // 所以如果x < -149，结果为0
        if (x < -149) {
            return 0;
        }

        // 非规格化数情况：指数为0
        // 值 = 0.尾数 × 2^(-126) = 尾数 × 2^(-149)
        // 要得到2^x，需要：尾数 × 2^(-149) = 2^x
        // 所以：尾数 = 2^(x+149)
        int shift = x + 149;

        // 检查shift是否在有效范围内
        if (shift >= 0 && shift < 23) {
            return 1 << shift;  // 符号位0，指数0，尾数为1<<shift
        }
        return 0;  // 太小，返回0
    }

    // 情况3：正常的规格化数
    // 2^x = 1.0 × 2^x，指数部分就是x+127
    // 符号位0，指数为exp，尾数为0
    return exp << 23;
}
```
